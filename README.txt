PULSE ONE — PRODUCT LANDING PAGE (LEVEL 1 TASK 2)

FILES
- index.html: page structure and small JavaScript for the mobile menu/current year
- style.css: page styling and responsive layout

RUN IN VS CODE
1. Extract this ZIP.
2. Open VS Code > File > Open Folder > select product_landing_page.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (install Live Server extension if needed).
   You can also open index.html directly in a browser.

CUSTOMIZE BEFORE SUBMISSION
- Update the product name, details, price and contact email as you like.
- Images load from Unsplash, so internet access is needed to display them.
- The price, battery figure and testimonial are demo content, not verified product claims.
- This project uses HTML and CSS for layout/design, plus a few JavaScript lines for mobile navigation.
